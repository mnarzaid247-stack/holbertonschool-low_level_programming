# Holberton School - Low Level Programming (C)

This repository contains my solutions and practice projects from the Holberton School Low-Level Programming curriculum.  
The focus is on building strong foundations in C programming, memory management, data structures, and basic system programming.

---

## Overview

Throughout this repository, I implemented core programming concepts in C including:

- Variables, conditionals, and loops
- Functions and nested loops
- Pointers, arrays, and strings
- Recursion
- Dynamic memory allocation (malloc & free)
- Command-line arguments (argc, argv)
- Function pointers
- Structures and typedef
- Variadic functions
- Singly and doubly linked lists
- Hash tables
- File I/O and system calls

Each directory represents a standalone project or topic from the curriculum.

## Requirements

- OS: Linux (Ubuntu recommended)
- Compiler: gcc
- Compilation flags used:

```bash
gcc -Wall -Werror -Wextra -pedantic -std=gnu89
```

---

## How to Use

1. Clone the repository:

```bash
git clone https://github.com/mnarzaid247-stack/holbertonschool-low_level_programming.git
cd holbertonschool-low_level_programming
```

2. Navigate to a specific project directory:

```bash
cd hello_world
```

3. Compile C files (example):

```bash
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 *.c -o main
./main
```

Note: Compilation steps may vary depending on the specific project task.
